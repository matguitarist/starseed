## Signed and notarized by Apple

- Starseed is now signed with an Apple Developer ID and notarized by Apple: new installs open without the "Open Anyway" step.
- After this update, macOS may ask once for Keychain access to your Nexus API key (the app's signature changed). Click **Always Allow**.
- "Mod Manager Download" links for Baldur's Gate 3 mods now go to Tadpole, if it's installed.
