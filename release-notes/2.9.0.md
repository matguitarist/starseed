## The same Help menu as every app

- **What's New in Starseed** opens the latest release notes.
- **Report a Problem…** opens a new GitHub issue with the app version, build and macOS version already filled in.
- **Check for Updates…** is always in the Starseed menu, greyed out when updates aren't available.
- The mods' item is now **Check for Mod Updates**, so it isn't confused with app updates.
