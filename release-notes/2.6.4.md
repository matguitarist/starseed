## Fixes across the app

- SMAPI Log: the sidebar and status bar no longer disappear when the log reports problems. A long "What SMAPI is telling you" list now scrolls.
- Update All no longer downloads a mod twice when it has several parts, such as Stardew Valley Expanded.
- Updates says "Couldn't Check for Updates" or "Not Checked Yet" instead of "All Mods Up to Date" when nothing was actually checked, and tells you when a Nexus API key is needed.
- Installed: more room for mod names, and rows stay the same height when an update is available. The sidebar and the filter field are no longer squeezed in a small window.
- Notes in Requirements, Saves and Find a Broken Mod wrap instead of being cut off.
- Counts read correctly for one item in every language ("1 mod", "1 update available").
- What's New shows its arrow on the Updates page, the lines between rows line up in Browse and Collections, and the Nexus API key link in Settings looks like a link.
